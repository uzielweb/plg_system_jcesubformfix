Integration In Joomla 6

A robust, elegant, and 100% upgrade-safe system plugin for Joomla 6. It seamlessly resolves JCE iframe callback failures and DOM ID corruptions inside repeatable subforms.

Download v1.0.0 (Zip) View Repository

Demonstrates the callback breakdown: clicking "Insert Selected" in the JCE modal does absolutely nothing because JCE attempts to execute obsolete Joomla 3 callback routines.

Technical Features

🛡️

Capture-Phase Interception

Intercepts the subform-row-add event in the capture phase before JCE's jQuery event bubbling executes. This records and protects correct field IDs from JCE corruption.

🔗

Dynamic DOM & URL Restoration

Automatically restores the uniquely generated input IDs, updating all JCE wrapper parameters, iframe source strings, and link references.

🌉

Web Component Bridge

Wraps the JCE iframe's editor functions, capturing file insertions and executing the native .setValue(url) method on Joomla 6 <joomla-field-media> components.

⚡

Zero Core Changes

100% upgrade-safe. Absolutely no physical overrides or edits to JCE Core or Joomla files. Keep updating JCE freely without losing functionality.
